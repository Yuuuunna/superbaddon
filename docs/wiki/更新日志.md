## 版本字符串不一致

核对提交中，gradle.properties 写的是 mod_version=1.0.0，src/main/resources/META-INF/mods.toml 则使用固定 version="1.0.1"。旧 README 中的卓越前线最低版本也比运行时元数据的 0.8.9.1 更旧／更宽泛。

不能由这些差异推测两个已经核实的发布里程碑。报告问题应提供实际 JAR 文件名／哈希和已知源码提交。依赖兼容应依据核对后的声明与实际运行测试，而非猜测更新历史。

## 今后的更新记录方式

只有能关联实际标签、发布或提交时，才增加正式版本条目；明确变更涉及代码、默认值、格式还是文档。行为变化应记录迁移步骤和重载／重启要求，并同步维护中英文页面。

历史说明与当前参考应分开保存，把旧示例直接复制到新版本不等于迁移。详见[数据格式版本](数据格式版本)。
