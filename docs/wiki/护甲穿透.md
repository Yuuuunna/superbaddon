# 护甲穿透

[English](Armor-Penetration) | [配置总览](配置总览)

护甲穿透使用独立的 `config/superbaddon/armor_penetration.json`，作用于卓越前线受支持伤害路径中的生物实体目标，不是通用护甲属性编辑器。

---

## 完整默认配置

自动生成文件还可能包含说明文字，并将比例序列化为字符串。以下数值形式和带引号的百分比都受支持。

```json
{
  "enabled": true,
  "armor_penetration_by_weapon": {
    "superbwarfare:small_cannon_shell": 0.8,
    "superbwarfare:grapeshot": 0.35
  },
  "full_armor_bypass_weapons": [
    "superbwarfare:cannon_shell",
    "superbwarfare:small_rocket",
    "superbwarfare:medium_rocket",
    "superbwarfare:rpg_rocket_standard",
    "superbwarfare:rpg_rocket_tbg",
    "superbwarfare:wire_guide_missile",
    "superbwarfare:javelin_missile",
    "superbwarfare:agm_65",
    "superbwarfare:kh_39",
    "superbwarfare:igla_9k38_missile",
    "superbwarfare:ru_9m336_missile",
    "superbwarfare:swarm_drone",
    "superbwarfare:mk_82",
    "superbwarfare:sc_50",
    "superbwarfare:sc_250",
    "superbwarfare:mortar_shell"
  ],
  "explosion": {
    "minimum_outer_penetration": 0.35,
    "inner_radius_factor": 0.35,
    "outer_falloff_power": 2.0
  }
}
```

<a name="lookup"></a>
## [1] 开关、适用范围与 ID 查询

`enabled` 默认 true，控制的是**配置查询**。受支持的伤害类型为卓越前线的弹射物直击、霰弹命中、弹射物爆炸和自定义爆炸，还要求实际经过本附属伤害钩子、目标为 LivingEntity。

受支持弹射物先按其记录的枪械物品 ID 查询，再按弹射物实体类型 ID 查询，最后回退到弹射物自带的穿透率。有效正值会被采用，零值或未命中可能继续回退。同一个配置 ID 同时存在于全穿透集合和部分穿透表时，全穿透优先。

> [!IMPORTANT]
> 将某个映射值设为零，不会否决后续实体类型或弹射物原生穿透率回退。`enabled: false` 同样只是关闭本文件查询，不会移除弹射物自身穿透率。因此不能把它描述成“关闭所有来源的穿透”。

应使用伤害来源实际携带的弹射物／枪械 ID，而不是显示名或猜测的载具模型名。除非确实希望广泛生效，否则不要为通用弹射物 ID 设置全局规则。

<a name="partial"></a>
## [2] 部分穿透

数值限制在 0–1。`0.35` 和 `"35%"` 都表示 35%；直接填写 `35` 会被限制为 1，不会按 35% 理解。

计算器将请求伤害 D 拆成穿透部分 `D × p` 和可防御部分 `D × (1 - p)`。可防御部分经过护甲、魔法减伤和吸收，穿透部分直接加入最终生命伤害。它不是简单扣除目标 p 比例的护甲属性，也不是对已经减伤的总伤害做线性插值。

实现使用了专用的生命伤害路径，仍保留非正伤害、客户端、已死亡目标、相关无敌／火焰免疫、创造／旁观玩家和队伍友伤等检查。这并不等于与所有其他模组的伤害事件或防御机制都兼容。

<a name="full"></a>
## [3] 完全穿透

`full_armor_bypass_weapons` 中的 ID 在考虑距离衰减前获得完整配置穿透。部分穿透值达到实现阈值 **0.999** 或以上时，也会进入完整穿透路径。

完全穿透不意味着任何实体都能被伤害，也不会无条件移除安全和队伍检查。全穿透弹射物产生的爆炸，离中心较远时仍可能只有较低的有效穿透率。

<a name="explosion"></a>
## [4] 爆炸距离衰减

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `minimum_outer_penetration` | 0.35 | 外圈下限，且不超过来源穿透率，不能反过来增强低穿透来源 |
| `inner_radius_factor` | 0.35 | 内段占半径的比例，限制在 0–1 |
| `outer_falloff_power` | 2.0 | 外段曲线指数，最小 0.1 |

距离比例使用爆炸中心到目标位置的距离除以半径，并限制在 0–1。内段**不是完全不衰减**：到内段边缘时，已经完成总下降幅度的 15%；外段再按指数承担剩余 85%。

来源穿透为 1、使用默认参数时：

| 相对距离 | 有效穿透率 |
| --- | --- |
| 中心 | 1.0 |
| 半径的 35% | 0.9025 |
| 半径的 100% | 0.35 |

这里修改的是穿透率，不是爆炸自身的伤害衰减或[击退](击退配置)。源码还为受支持的卓越前线延迟冲击波保留上下文；没有可解析上下文的任意其他爆炸不会自动获得支持。

<a name="commands"></a>
## [5] 重载、状态与自动补全

```text
/superbaddon armor_penetration reload
/superbaddon armor_penetration status
/superbaddon armor_penetration autofill
```

均要求权限等级 2。reload 重读 JSON；status 输出加载数量和路径，不是每次伤害实际穿透率的诊断器。

autofill 扫描已加载的主模组载具武器定义，只添加尚未配置的 ID。分类依据已有穿透数据、文本／名称提示以及伤害和爆炸阈值，例如为识别出的机炮、机枪族提出部分穿透，为识别出的重型／爆炸武器提出完全穿透。它会避免自动加入通用实体 ID `superbwarfare:projectile`，但存在有效的具体武器 ID 时仍可能添加该武器。

这些是启发式候选，不是实测穿甲性能。先备份有效 JSON，再检查新增条目和日志，最后测试直击与多个爆炸距离。已有配置 ID 会保留；反复执行 autofill 不是恢复默认值的方式。

## 旧输入与错误处理

兼容部分 camelCase 字段名，以及 `"namespace:id=35%"` 数组形式；维护时优先使用上面的 snake_case 对象／数组形式。不要同时填写两套名称：旧部分穿透表在规范表之后读取，全穿透集合则会合并。旧根级爆炸参数也有兼容读取，嵌套 explosion 字段优先。详见[数据格式版本](数据格式版本)。

格式错误可能触发警告并使用默认值。不要对未经检查的错误配置执行写入类命令，并假设原始文字必然被完整保留。
