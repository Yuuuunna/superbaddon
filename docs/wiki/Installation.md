# Installation

## Requirements

- Minecraft 1.20.1
- Forge 47.4.0
- Java 17
- SuperbWarfare installed

## Install Steps

1. Install Forge 47.4.0 for Minecraft 1.20.1.
2. Put SuperbWarfare into the `mods` folder.
3. Put SuperbAH6 into the `mods` folder.
4. Start the game once to generate configuration files.
5. Edit files under `config/superbah6` as needed.
6. Restart the game/server after changing content-control rules.

## Server Notes

Server-side configuration should be treated as authoritative.
Do not assume client-only changes can disable server content.
