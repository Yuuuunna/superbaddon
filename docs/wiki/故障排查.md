# 故障排查

[English](Troubleshooting) | [已知问题](已知问题)

修改前先保留出错配置与完整相关日志。反复扫描、删除配置或一次改变多个系统，都可能破坏定位问题所需的证据。

---

## [1] 先确定失败层级

| 症状 | 首先检查 | 下一步 |
| --- | --- | --- |
| 游戏／服务端无法加载附属 | 依赖错误、Java／Forge 版本、重复 JAR | 按[安装](安装)处理，保留完整异常链 |
| 找不到 /superbaddon | 服务端是否加载模组、是否有权限等级 2 | 从控制台测试，不要靠改 JSON 修复命令注册 |
| 外部文件被拒绝 | JSON 语法、format: 5、rules 数组、target 对象 | 严格校验 JSON，查看[数据格式版本](数据格式版本) |
| 规则加载但武器没变化 | 实例目录、ID、目标交集、优先级、开关 | 缩减到[快速开始](快速开始)的单目标示例 |
| 载具新成本没显示 | 实际 result.entity ID、配方是否已被删除、重载方式 | 服务端 /reload，检查匹配／移除日志 |
| 资源仍然可见 | 客户端本地配置／缓存和受支持路径 | 对齐文件后重启对应实例 |
| 矿石仍然存在 | 是否观察旧区块 | 检查新地形，开关不会删除旧矿石 |

## [2] 抛壳问题

没有弹壳时，检查选中的模式、弹药条目、概率、第一个点的弹壳物品以及存储目标。store 只处理第一个点，库存已满且 fallback_to_drop 为 false 时不会回退掉落。内容控制也可能在生成后拒绝对应弹壳物品。

出现意外弹壳时，检查更高优先级规则、误留的空目标全局规则和复制的备份 JSON。规则 enabled 为 false 不会压制较低规则，count 为零会被限制成一，根 enabled_by_default 也不会关闭规则。

位置错误时，先只保留一个点，关闭移动干扰并测试多个朝向。偏移使用发射方向／世界向上的基准，不是动画骨骼或包含载具完整滚转的基准。详见[抛壳配置](抛壳配置)。

## [3] 弹药与击退问题

弹药补丁需要所属规则与覆写开关都启用、allowed 非空，并具有定义目标。只指定弹射物不会修改定义。同优先级 replace 会合并，append 也可能加入未预期选项。删除补丁后应重启或验证完整数据还原，外部重载不是基线重置。

击退有独立的直击和爆炸通道，但从一条规则选择整份配置。纯 inherit 的高优先级配置不会屏蔽较低活动规则；正数 min 可将 disabled 得到的零重新抬高。已有自定义强度及绕开受支持伤害／速度路径的实现仍可能决定移动。详见[弹药覆写](弹药覆写)和[击退配置](击退配置)。

## [4] 配方与内容问题

普通物品／方块 recipes_only 未删除配方，是已注明的实现缺口，不一定是 JSON 错误。标签和动态输出也限制通用过滤能力。载具配方应检查组冲突、单体整份替换和无效材料数组。

内容控制重载不是配方表重建；配方被其他规则或脚本删除时，材料覆写不会让它复活。方块仍留在世界里时，要注意方块资源过滤不拦截通用放置，也不卸载 BlockEntity。详见[配方禁用指南](配方禁用指南)。

## [5] 穿透问题

确认受支持伤害类型和直接弹射物携带的 ID。枪械 ID、实体类型与原生穿透率的查询顺序很重要，零值或未命中可能继续回退；关闭配置查询不等于消除原生穿透。

分别测试直击和多个爆炸距离。默认爆炸穿透在内段已经衰减，全穿透来源不会在整个半径都保持完全穿透。比较时固定目标护甲、吸收、队伍和游戏模式，详见[护甲穿透](护甲穿透)。

## [6] MTS 与合成问题

MTS 燃料应检查根／子功能开关、规范化后的液体键、整表替换、载具实际能量容量和附近目标选择。当前有效读取器不允许把油泵搜索半径降到 32 以下。连接不持久保存，重启后需重连。

操控应先绑定默认未分配的按键，开启正确开关并坐到控制座位。倾斜视角和输入替换彼此独立。弹药盒检查 bulletQty，不能把物品数量直接当成发数。

弹壳合成应将所需弹壳集中为一格的一堆，其他材料各占一格，移除多余物品。先验证标准合成界面，再检查自动化模组，详见[MTS兼容](MTS兼容)与[弹壳复装](弹壳复装)。

## [7] 有效的问题报告

提供实际模组／JAR 版本、已知源码提交、单人或独立服务端环境、具体命令／操作、预期和实际结果，以及能复现的最小配置与目标 ID。多人或界面相关错误，应同时提供服务端和客户端日志。

保留第一个相关异常及完整 caused-by 链，不要只截最后一行断开连接提示。分享前移除账号令牌、无关个人路径和服务器凭据。说明执行过哪种重载／重启，以及在测试世界的新武器／新载具上是否复现。
