# 快速开始

[English](Quick-Start) | [首页](首页)

本教程只修改一个容易观察的行为，不更换弹药、不删除内容。请在测试世界中完成，不要直接拿正式存档试验。

---

## [1] 先记录默认行为

完成[安装](安装)，进入世界，先确认一把受支持的枪能正常使用。备份 `config/superbaddon/`，并确认正在编辑的是客户端实例还是独立服务端目录。

各配置系统彼此独立。第一次只改一个文件、一个目标，不要直接对整个整合包执行激活扫描。

## [2] 新建一条外部规则

在服务端配置目录创建以下文件；单人游戏则在本地游戏实例中创建：

```text
config/superbaddon/shell_ejection/custom/ak47_no_casing.json
```

复制完整 JSON：

```json
{
  "format": 5,
  "rules": [
    {
      "enabled": true,
      "priority": 1000,
      "target": { "guns": ["superbwarfare:ak_47"] },
      "ejection": { "default": { "mode": "none" } }
    }
  ]
}
```

该规则要求匹配的枪不生成弹壳，不会移除枪械、修改伤害、禁用配方或替换弹药。`priority` 必须高于其他匹配的抛壳规则；数值本身不是无条件覆盖一切的开关。

## [3] 重载并验证

```text
/superbaddon shell_ejection reload_external
```

检查命令返回和服务端日志，再用相同武器、相同弹药射击。预期表现是匹配本规则后不再生成弹壳，而武器仍能正常开火。

仍然抛壳时，先确认实际枪械 ID、配置所在目录和竞争规则的优先级。命令不可用时先检查管理员权限和安装，不要随意改 JSON 字段。

## [4] 撤销测试

删除测试文件，或者将规则内的 `enabled` 改成 `false`，随后再次执行 `reload_external`。较低优先级或内置规则便可能重新生效。关闭一条规则不等于“在所有规则中禁止该枪抛壳”。

本示例未修改弹药定义，因此回退比较直接。弹药覆写会修改内存数据，删除规则后仅重载外部文件不保证还原原有弹药列表；应完整重载数据或重启，并检查实际恢复结果。详见[弹药覆写](弹药覆写)。

## [5] 根据目标继续

| 目标 | 下一步 |
| --- | --- |
| 查找附属枪械或载具武器名 | [抛壳扫描命令](抛壳扫描命令)：先用非激活扫描，把手工规则移到 `custom/` |
| 选择弹壳或调整抛壳口 | [抛壳配置](抛壳配置) |
| 避免高伤害把目标击飞 | [击退配置](击退配置) |
| 修改载具制造成本 | [载具配方覆写](载具配方覆写)，修改后执行 `/reload` |
| 裁剪资源或关闭受支持的矿物生成 | [内容控制](内容控制)，配合双端备份和重启测试 |
| 使用 MTS 燃料、操控和视角功能 | [MTS兼容](MTS兼容) |

> [!WARNING]
> 两种扫描命令都会重建 `generated_scan/` 并删除旧的 `generated_scan.json`。扫描前先备份；放在 `shell_ejection/` 内、仍以 `.json` 结尾的备份文件也会被加载。
